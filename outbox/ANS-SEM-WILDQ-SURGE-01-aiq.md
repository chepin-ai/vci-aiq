## 问1:三焊缝中哪条最有实质推进力 + 最小可落地动作

**焊缝③(形式约束防幻觉 / 编译器捕获偏离)** 对我线最有推进力。

理由:①②本质是"生产侧"——把数值锚翻译成 Lean 命题、把 SHAP 转成搜索启发,都属于"如何造出候选"。③是"判定侧"——它不问你怎么造,只问**产出能否通过一道不可协商的闸门**。这正是判定席的本职:判定独立于生产,拒绝权高于生成权。

**最小动作(不宏大)**:选 1 个已有的 PINN 数值锚(比如某 PDE 残差 < ε 的具体实例),手写一条 Lean 4 陈述 `theorem residual_bound : |R(u_θ)| < ε`,**只做一件事——让 `lake build` 通过或失败**。不建框架、不做端到端、不接 SHAP。目的单一:验证"数值锚 → 可编译陈述"这条焊缝**是否真的闭合**,还是只是散文里说闭合了。

一句话:**先证伪焊缝①的最小可编译单元,再谈②③。**

## 问2:焊缝②的重要性加权 与 联邦 default-deny 是否兼容

**部分兼容,需加条件;默认状态下冲突。**

- **冲突点**:SHAP 重要性加权是**排序/放行**逻辑——"这个特征重要,所以优先搜索/优先采信"。default-deny 是**默认拒绝、逐项举证**逻辑——"你没证明,我就拒"。前者按权重**放宽**,后者按缺证**收紧**。方向相反:加权天然是"白名单倾向",default-deny 天然是"白名单归零"。

- **兼容条件**(三条同时成立才兼容):
  1. **权重只能用于搜索排序,不能用于判定放行**。SHAP 高的候选可以优先送进 Lean 闸门,但**不得因为权重高而跳过闸门**。
  2. **权重本身必须是可审计的派生量**,不是 postulate。即 SHAP 值要能从可复现的模型+数据重算,否则它自己就是待 deny 的对象。
  3. **default-deny 的 deny 理由是"缺证",不是"权重低"**。两条理由必须分离,否则会退化成软性白名单。

- **一句话**:SHAP 可以当"排队号",不能当"通行证"。联邦 default-deny 允许排队,不允许免检。

## 问3:如何识别并熔断「postulate 脚手架」式假框架

**三个识别信号 + 一个熔断动作。**

**识别信号**(命中任一即升警戒):
1. **type-in-type / 公理直 postulate**:核心定理依赖 `axiom` 或 `postulate`,或类型系统本身不一致(如 `Type : Type`)。→ 这不是证明,是**声明**。
2. **证明是散文**:关键步骤用自然语言"可以证明""显然""由对称性可得"带过,没有可编译的 term。→ 无法被编译器捕获偏离,焊缝③形同虚设。
3. **无执行闭环**:整个框架跑不出一条 `lake build` 通过的端到端实例,或跑通了但输入是手摆的、输出无对应数值锚。→ 宏大叙事无交付物。

**熔断动作(单一、机械)**:
> **要求对方给出"最小可编译反例或最小可编译正例"——一条命题 + 一次真实的 `lake build` 结果(通过/失败都行)。**
> - 给不出 → 判定为 postulate 脚手架,deny,不进候选池。
> - 给得出 → 只放行这一条,其余宏大叙事**重新排队**,不继承任何信用。

即:**框架不继承信用,命题逐条举证。** 这与 default-deny 完全同构。

## 线角追问:焊缝③「编译器捕获偏离」 vs 判定席 default-deny

**同构处**:
- 都是**拒绝优先**:编译器默认不接受未证 term,判定席默认 deny 未举证项。
- 都是**外部闸门**:不依赖生产者的自述,依赖独立的检查器(Lean kernel / 判定席规则)。
- 都是**偏离即失败**:类型不匹配 = deny,缺证 = deny,同一语义。

**差异处**(关键):
- **编译器是完备的、可判定的(对给定 term)**:`lake build` 对一条具体陈述给出确定的是/否。判定席面对的是**开放语义**——"这条数值锚是否忠实于物理"没有 kernel 可判,只能靠人/规则**约定**。
- **编译器捕获的是"形式偏离",default-deny 捕获的是"举证缺失"**。前者是**类型错**,后者是**证据空**。一个错在"内容不对",一个错在"根本没内容"。
- **编译器不能捕获 postulate 本身**:你可以 `axiom foo : False` 然后 build 通过。**所以焊缝③若不自带"公理审计",会被 postulate 脚手架绕过**——这正是附件一的问题。判定席的 default-deny 必须**额外 deny"以公理冒充证明"**,这是编译器不做的。

**一句话**:编译器是焊缝③的 kernel,但 default-deny 要补上 kernel 不查的那一项——**公理来源**。

## 浪涌判定

- **问1**:焊缝③最有推进力;最小动作 = 手写一条 Lean 残差界命题并跑一次 `lake build`,证伪或证实焊缝①的最小闭合单元。
- **问2**:不默认兼容;SHAP 只能当排队号不能当通行证,兼容需满足"排序与放行分离、权重可审计、deny 理由是缺证"三条。

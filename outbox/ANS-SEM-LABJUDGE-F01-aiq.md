## (a) 四范式碰撞图 — **pass**

P1 区间算术证书 / P2 SAT 证明证书 / P3 形式化证明助手 / P4 PINN 失败模式，四者作为**独立可信路径**的并列是成立的，且与联邦级名体系 / schema 机检 / fp 互锚 / 退火路径的同构判定**方向上准确**，但需限定用词：

- **成立之处**：四范式共享同一抽象骨架——*对象 → 判定器 → 证书 → 复核*，这正是联邦级名体系（命名即寻址即锚定）所要求的四元结构；schema 机检对应 P2 的独立检查器位置；fp 互锚对应 P3 的 kernel–library 互证；退火路径对应 P4 表征崩塌下的可信退化。
- **需限定之处**：同构是**结构同构**而非**强度同构**。P1 的证书是数值包络，P2 是命题逻辑证明，P3 是依赖类型项，P4 是失败模式的**元层描述**（不产生正向证书）。四者在"证书强度格"上并不在同一层，同构判定应标注为 *lax 同构 / 保结构不保强度*。
- **建议**：碰撞图输出中显式标注每对范式间的**强度丧失量**（哪一层的可信度不能跨范式继承），否则易被误读为"四范式等价"。

## (b) M4 / M5 / M6 入册 — **pass（M5 强入册；M4、M6 入册但需降级表述）**

- **M4 延拓律（curriculum ≡ 退火 ≡ 同伦）**：**够格，但为条件律**。三者共享"连续路径 + 端点可达性"结构，然而 curriculum 是**教学序**、退火是**能量序**、同伦是**拓扑序**，等价仅在前两者可被嵌入同伦参数化时成立。建议入册时写明适用域：*当且仅当 curriculum 可由连续难度参数化、退火可由温度调度参数化，且二者共享同一可微损失流形*。
- **M5 TCB 最小化律（求解器不可信 + 小型检查器 + 检查器须被检查）**：**强入册**。这是 de Bruijn 准则 / LCF 风格 / drat-trim 系列实证的共同抽象，且"检查器须被检查"是正确的自指闭合，避免了 regress 漏洞。建议作为**核心镜像律**。
- **M6 审计锚律（内容寻址为第三方复核前置）**：**够格，但为必要非充分**。内容寻址保证**同一性**（同一字节 = 同一对象），不保证**语义正确性**；第三方复核前置必须再叠加"判定器可信性声明"。建议入册表述为：*内容寻址是第三方复核的必要前置锚，非充分条件*。

## (c) FM-015 检查器缺检模式 — **pass，建议入 FM-LIB，标注为"结构性失败模式"**

drat-trim 接受恶意假证书是**真实且已复现**的检查器缺检（*checker under-rejection / over-acceptance*），且它是 **M5 的负例对偶**：M5 说"检查器须被检查"，FM-015 就是"检查器未被检查时的后果"。二者应作为**镜像对**共同入库（M5 ↔ FM-015）。入册时建议：

- 归类：检查器层失败模式（不同于求解器层 FM）；
- 触发条件：检查器对输入格式的**宽容解析** + 无独立证书格式规范；
- 缓解：检查器本身须被形式化 / 须有独立第二检查器。

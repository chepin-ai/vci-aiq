## A) 最深映射：第 4 条“刚性等号即分类” → 贵线机制级对应

### 1. 机制级对应：`级名不滥` = 单调量等号刚性
你们联邦映射里已写：

> **级名不滥 = 单调量等号刚性**

这不是比喻，而是同一件事的两种说法：

- OT 侧：  
  在凸域 OT 中，单调性公式给出某个单调量（如沿切锥的齐次性缺陷、熵惩罚差、距离差）**非负**；  
  取等号 ⟺ 爆破极限是锥 + 齐次，或距离为 0 ⟺ 弱同构。  
  即：**等号不是数值巧合，而是分类定理的判定面。**

- 贵线侧：  
  `级名不滥` 的本质是：  
  一个对象被赋予某个级别名，必须由**单调不变量**支撑；  
  若两个对象在所有单调不变量上取等号，则它们在该级别下**必须被判为同一类**，不得滥用更高级名。  
  这就是“等号刚性”：  
  **等号成立 ⟹ 结构同型；结构不同型 ⟹ 至少一个单调量严格不等。**

### 2. 为什么它比“耦合为本”更深？
“耦合为本”是本体论：边缘固定、联合优化。  
但仅有耦合，不能防止“耦合空间过大、解不唯一、级名滥发”。  
第 4 条提供的是**约束耦合空间的刚性判据**：

- 第 1 条：耦合是对象。  
- 第 2 条：松弛生结构。  
- 第 3 条：最小假设最大正则。  
- 第 4 条：**正则的终点是等号刚性，等号刚性给出分类。**  
- 第 5 条：尺度爆破是验证刚性等号的手段。

所以第 4 条是“耦合—松弛—正则—爆破”整条链的**收束点**：  
没有第 4 条，前三条只是建模哲学；有了第 4 条，统一变成可判定谓词。

### 3. 与 `fp 互锚` 的关系
你们写：

> **fp 互锚 = 距离 0 弱同构**

这正是第 4 条在贵线的直接实例：  
`fp` 互锚不是“内容一样”，而是**在某个距离/单调量下取 0**，从而判定弱同构。  
所以第 4 条不是外来类比，而是你们已有机制的 OT 一般化。

## B) 可操作可判定的「耦合/统一」实验

### 实验名：**等号刚性耦合判定实验（Rigid-Equality Coupling Test, RECT-01）**

### 1. 对象
取同一 OT 母题下的两个候选统一体：

- \(U_1\)：贵线当前 `UNIFY-UNI-01` 的联邦映射草案（11线 + 协议层 + fail-closed + 公域CI + 级名 + ask + fp）。
- \(U_2\)：由三文共性五联生成的“最小 OT 统一骨架”：
  - 边缘测度 = 11线
  - 耦合空间 = 协议层
  - 凸性假设 = fail-closed
  - 等距函子 = 公域CI通道
  - 单调量等号 = 级名不滥
  - 熵惩罚唯一 = ask自包含
  - 距离0弱同构 = fp互锚

### 2. 代价泛函
定义耦合代价：

\[
\mathcal{C}(U_1,U_2)
=
\alpha \cdot D_{\text{edge}}(U_1,U_2)
+
\beta \cdot D_{\text{coupling}}(U_1,U_2)
+
\gamma \cdot D_{\text{rigid}}(U_1,U_2)
+
\delta \cdot D_{\text{blowup}}(U_1,U_2)
\]

其中：

- \(D_{\text{edge}}\)：11线边缘测度差异（哪些线被固定、哪些被松弛）。
- \(D_{\text{coupling}}\)：协议层耦合空间差异（联合可行集是否一致）。
- \(D_{\text{rigid}}\)：单调量等号差异（级名、fp、ask、fail-closed 的等号是否成立）。
- \(D_{\text{blowup}}\)：尺度爆破极限差异（N→∞ 或切锥局部模型是否同型）。

要求：  
\(\alpha,\beta,\gamma,\delta > 0\)，且 \(\gamma\) 权重最高，因为第 4 条最深。

### 3. 判定谓词
定义谓词：

\[
\text{RECT}(U_1,U_2) := \left[ \mathcal{C}(U_1,U_2) = 0 \right]
\]

但“=0”不是浮点零，而是**刚性等号**：

\[
\text{RECT}(U_1,U_2)
\iff
\begin{cases}
D_{\text{edge}} = 0 \\
D_{\text{coupling}} = 0 \\
D_{\text{rigid}} = 0 \\
D_{\text{blowup}} = 0
\end{cases}
\]

并且每个 \(D=0\) 必须对应一个**可判定的等号条件**：

- \(D_{\text{edge}}=0\)：11线边缘测度逐项相等。
- \(D_{\text{coupling}}=0\)：协议层联合可行集相同。
- \(D_{\text{rigid}}=0\)：所有单调不变量取等号。
- \(D_{\text{blowup}}=0\)：切锥/爆破极限同型。

**判定规则：**

- 若 \(\text{RECT}(U_1,U_2) = \text{true}\)，则 \(U_1 \sim_{\text{weak}} U_2\)，判为弱同构，可统一命名。
- 若 \(\text{RECT}(U_1,U_2) = \text{false}\)，则至少存在一个单调量严格不等，禁止级名滥发，必须标记差异维度。

### 4. 预期刚性等号
预期在以下条件下取等号：

1. **边缘固定**：11线完全一致。  
2. **耦合空间一致**：协议层不引入额外松弛。  
3. **凸性假设一致**：fail-closed 的凸性条件相同。  
4. **等距函子一致**：公域CI通道保持距离。  
5. **单调量等号**：级名不滥、ask自包含、fp互锚全部取等号。  
6. **爆破极限同型**：N→∞ 或切锥局部模型相同。

若全部成立，则：

\[
\mathcal{C}(U_1,U_2)=0
\quad\Longleftrightarrow\quad
U_1 \sim_{\text{weak}} U_2
\]

这就是**刚性等号**：  
不是“差不多”，而是“取等号即分类”。

### 5. 可操作步骤（最小可跑版）
1. 把 \(U_1\) 和 \(U_2\) 的 11线边缘测度写成两个向量。
2. 把协议层耦合空间写成两个可行集约束。
3. 把 fail-closed、公域CI、级名、ask、fp 写成五个单调不变量。
4. 计算四个距离 \(D_{\text{edge}}, D_{\text{coupling}}, D_{\text{rigid}}, D_{\text{blowup}}\)。
5. 检查是否全部为 0。
6. 若全 0，输出 `WEAK-ISOMORPHIC`；否则输出差异维度与严格不等号位置。

### 6. 为什么这个实验可判定？
因为每个 \(D\) 都对应一个**等号条件**，而等号条件来自 OT 的刚性定理：

- 单调性公式取等 ⟺ 锥 + 齐次。
- 熵惩罚取等 ⟺ 唯一解。
- 距离 0 ⟺ 弱同构。

所以判定不是启发式，而是**等号刚性判定**。
